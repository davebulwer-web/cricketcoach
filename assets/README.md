# Art assets

All the game's art is in this folder as PNG files. Everything here is
placeholder art, and any file can be replaced with your own drawing of the
same size and layout. No code changes are needed.

The placeholders are generated by `node tools/make-placeholder-art.js`, so
re-running that script overwrites this folder's PNGs. Once you add your own
art, stop using the script (or remove the files you've replaced from it).

| File | Size | Layout |
| --- | --- | --- |
| `players.png` | 112 x 48 | Seven 16 x 24 frames in a row (see below), with a second row of team-colour masks |
| `props.png` | 48 x 16 | Three 16 x 16 frames: `stumps`, `stumps_broken`, `ball` |
| `pitch.png` | 154 x 188 | The pitch close-up background on the match screen |
| `ground.png` | 133 x 133 | The top-down ground on the overview, transparent outside the boundary |

## Player frames

Left to right: `bat_stance`, `bat_swing`, `bowl_run1`, `bowl_run2`,
`bowl_release`, `keeper`, `fielder`.

Batters, the keeper and the fielder face the camera. The bowler is seen from
behind, running towards the batter at the top of the screen. `bowl_run1` and
`bowl_run2` alternate during the run-up.

## Team colours

The bottom row of `players.png` is a mask. Any white pixel in it is
recoloured with the team's colour (set in `js/data/teams.js`) and drawn over
the same pixel in the top row. Use it for caps, sweaters or trim. Leave the
mask empty (transparent) if a sprite should not change colour.

## Changing sizes or adding frames

Frame sizes and names are listed in `js/sprites.js`. If your art uses a
different frame size or extra frames, update that list too. Positions of the
players on the pitch view are in `PITCH` in `js/screens/match.js`, and they
line up with the creases drawn in `pitch.png`.
